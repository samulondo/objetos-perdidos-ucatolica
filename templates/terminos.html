Términos y condiciones

Este sistema es un MVP académico destinado a la demostración del registro, consulta y gestión de objetos perdidos y encontrados.

Uso del sistema

  • Utilizar el sistema para registrar, consultar y gestionar objetos.
  • Ingresar información veraz y pertinente.
  • No registrar datos personales reales durante demostraciones públicas.
  • Las credenciales son de demostración y no corresponden a una cuenta institucional.

Privacidad y datos

Los registros se almacenan localmente en una base de datos SQLite. Esta versión no es un servicio institucional oficial y no incluye recuperación de contraseña por correo.
